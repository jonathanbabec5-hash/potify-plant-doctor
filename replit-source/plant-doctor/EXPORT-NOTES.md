# Plant Doctor Replit source snapshot

Editable client, server, shared schema, dependency and build files copied from the Replit Plant Doctor project. This snapshot stays under its own folder so the repository's existing public handoff remains unchanged.

Restored the project-owned leaf-art hero background at `client/src/assets/images/hero-bg.png`. Added a new, original SVG favicon because the source PNG icon's origin and license could not be verified.

Not included: Replit-only instructions and agent notes, screenshots, diagnostic-photo fixtures, the screenshot-style OpenGraph image, private notes, environment values, database contents, or user records. Social-preview image tags were removed rather than publishing unverified imagery. The build was verified with the screenshot-style preview omitted.

For portable installs the working copy uses public npm tarball URLs with the original locked integrity digests. The build command loads TypeScript through Node. The original snapshot and recovered-art revision remain available in Git history.
