# Plant Doctor Replit source snapshot

Editable client, server, shared schema, dependency and build files copied from the Replit Plant Doctor project. This snapshot is preserved under its own folder so the repository's existing public handoff remains unchanged.

Excluded: Replit-only instructions and agent notes, screenshots, diagnostic-photo fixtures, and binary UI image assets. No environment values, database contents, or user records are included. The missing visual assets may need to be restored from the original project before running this snapshot.
